# Calculadora Mercado Livre Nativa

Aplicativo Android nativo, sem HTML e sem WebView.

## Recursos da versão 1.0
- cálculo de custo, taxa, preço recebido e lucro;
- tabela de margens de 0% a 100%;
- cadastro local de produtos;
- pesquisa;
- favoritos;
- abrir e atualizar consultas;
- renomear e excluir produtos;
- banco de dados SQLite;
- funcionamento 100% offline.

## Como gerar o APK no GitHub
1. Extraia o ZIP.
2. Envie todo o conteúdo interno para a raiz de um repositório vazio.
3. Confirme que existe `.github/workflows/gerar-apk.yml`.
4. Abra **Actions**.
5. Execute **Gerar APK Android**.
6. Baixe o APK em **Artifacts**.
